Where I help

Editorial strategy before audio cleanup.

A podcast is a publishing system: audience promise, episode architecture, host preparation, guest experience, production standards, release copy, promotion, and a repeatable workflow. Good sound matters, but the strongest shows usually begin with sharper editorial decisions.

Working process

A repeatable path from idea to episode

  1. Frame

    Clarify why the show exists, who it serves, what each episode should accomplish, and what the audience can reliably expect.

  2. Prepare

    Build guest research, interview questions, host notes, recording expectations, and the structure that keeps the conversation useful.

  3. Record

    Support the session with a clear run of show, contingency notes, and a shared understanding of what needs to be captured.

  4. Shape

    Review the material for structure, pacing, clarity, strongest moments, supporting copy, and what should be cut or clarified.

  5. Publish

    Create release copy, show notes, links, promotional language, file organization, and documentation for the next episode.
