Where I help

Editorial judgment paired with production discipline.

A print publication has to succeed as both content and a physical artifact. That means managing story hierarchy, deadlines, revisions, proofing, design handoffs, image and file requirements, and the final preflight without losing sight of the reader.

My background includes national magazine leadership, executive messaging, issue production, event dailies, proofreading, and conference instruction on preflighting publications. I can join for a single issue, repair a difficult workflow, or help a team build a repeatable production system.

Working process

A visible path to final files

  1. Scope

    Clarify the audience, format, printer specifications, schedule, decision-makers, and where the current production process is most exposed.

  2. Build

    Create the editorial calendar, review sequence, checklist, and file conventions the team will use through production.

  3. Review

    Examine content and pages in context, resolving inconsistencies and tracking corrections without creating version confusion.

  4. Preflight

    Perform the final production review, document open risks, and prepare a clear handoff for printing or distribution.
